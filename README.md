# YT ma być inteligentna

Skill / instrukcja dla Grok (i podobnych agentów AI) — pełny system produkcji i wzrostu kanału YouTube.

## Pliki

| Plik | Opis |
|------|------|
| `SKILL.md` | Główny system globalny (`yt-intelligent-global`) — aktywacja m.in. frazą **„YT ma być inteligentna”** |
| `youtube-creator.SKILL.md` | Wariant creator (pakiet produkcyjny + growth) |

## Jak użyć w Grok

1. Załącz `SKILL.md` do czatu **albo** zainstaluj jako skill (folder ze `SKILL.md`).
2. Napisz: **YT ma być inteligentna** albo konkretne zadanie (pełny pakiet na film, Shorts, strategia kanału…).

## Aktywacja

- „YT ma być inteligentna”
- „zrób mi inteligentny system na YouTube”
- „pełny pakiet na film”
- „Shorts + tytuły + miniatura”
- „strategia kanału”
- „zoptymalizuj ten film”

## Licencja

Użyj według własnych potrzeb. Treść to instrukcja operacyjna agenta, nie kod źródłowy VS Code.
